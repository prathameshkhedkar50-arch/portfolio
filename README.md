## 🚀 Getting Started

### Prerequisites

Install:

- Node.js
- npm
- Git

Check your installation:

```bash
node --version
npm --version
git --version
```

---

## 📥 Clone the Repository

```bash
git clone https://github.com/prathameshkhedkar50-arch/portfolio.git
```

Enter the project:

```bash
cd portfolio
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## ▶️ Start Development Server

```bash
npm run dev
```

Vite will display the local development address, typically:

```text
http://localhost:5173
```

Open it in your browser.

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

The generated production files will be available inside:

```text
dist/
```

---

## 👀 Preview Production Build

```bash
npm run preview
```

---
